Trouble Shooting

개발 중 직접 해결한 문제들

문제 상황

API 호출 시 매핑 주소가 /api/api/로 중복되거나, 예외 발생 시 상태 코드와 메시지 구조가 일관되지 않아 클라이언트 연동이 어려웠습니다.

원인 분석

프론트엔드 axios 호출 경로와 백엔드 API 호출 구조가 일관되지 않았습니다.

해결 방법

CloudFront 배포 도메인을 CORS 허용 목록에 추가하고, /api URI Prefix를 적용하여 API 경로를 일관되게 구성했습니다.

결과 / 배운 점

API 호출 경로와 예외 응답 형식을 통일하여 클라이언트 연동이 원활해졌습니다.

문제 상황

로컬에서는 정상 동작하던 API가 배포 환경에서 DB 연결 오류로 기동에 실패했습니다.

원인 분석

운영·개발 환경 변수 이름과 값이 달랐고, 설정 파일에 환경별 값이 하드코딩되어 있었습니다.

해결 방법

프로필별 설정을 분리하고 Docker·서버 환경 변수로 주입하도록 정리했습니다.

결과 / 배운 점

배포 전 환경 변수 체크리스트를 두면 재발을 줄일 수 있다고 정리했습니다.

문제 상황

JWT 토큰 만료 후 클라이언트에서 예외 처리가 되지 않아 연속적인 인증 에러(401/403) 및 화면 먹통 현상이 발생했습니다.

원인 분석

Axios 요청 시 만료된 토큰이 헤더에 계속 실려 전송되었고, 백엔드의 만료 응답에 대응하는 전역 인터셉터가 부재했습니다.

해결 방법

main.jsx
에 전역 Axios 인터셉터를 설정하여 API 요청 시 JWT를 자동 첨부하고, 만료(401/403) 시 스토어 초기화 및 메인 리다이렉트를 구현했습니다.

결과 / 배운 점

컴포넌트별 개별 처리 대신 전역 인터셉터를 활용해 중앙 집중식 인증 관리 구조를 구축하는 것의 중요성을 배웠습니다.
